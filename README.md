# EncoreAI

AI-powered concert and festival trip planner built with LangChain, LangGraph, and specialized AI agents.

## Overview

EncoreAI aims to simplify the planning of concert and festival trips by coordinating specialized AI agents.

The project is being developed as a modular Python application, with a focus on maintainability, testability, and extensibility.

## Planned Features

- Concert and festival research
- Accommodation discovery
- Flight and travel research
- AI agent orchestration with LangGraph
- Human-in-the-Loop review and confirmation

## Tech Stack

- Python
- LangChain
- LangGraph
- Pydantic
- Pytest

## Project Status

The project is currently in the initial restructuring stage. The original notebook will serve as the functional reference for the modular implementation.

## Security

Never commit API keys, access tokens, or other secrets. Store local credentials in environment variables and keep `.env` out of version control.
